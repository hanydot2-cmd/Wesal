# وصال – للتعارف والزواج الجاد (Wesal Marriage Platform)

تطبيق وموقع إلكتروني متكامل وفاخر باللغة العربية مخصص للتعارف الجاد بهدف الزواج الشرعي فقط.

---

## 🌟 المزايا والخصائص الأساسية

### 1. التصميم والهوية البصرية
- **لغة عربية بالكامل** بدعم الاتجاه من اليمين إلى اليسار (RTL).
- **ألوان هادئة وراقية**: وردي دافئ، ذهبي خفيف، بنفسجي هادئ، وأبيض.
- **تجاوب كامل** مع الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.
- **دعم الوضع الداكن والوضع الفاتح** (Dark Mode / Light Mode).

### 2. الأمان العالي والخصوصية
- **منع مشاركة وسائل الاتصال**: ماسح تلقائي حظر إرسال أرقام الهواتف، الواتساب، البريد الإلكتروني، والروابط.
- **مراجعة إدارية للصور الشخصية**: لا تظهر صور الأعضاء للعامة إلا بعد اعتماد الإدارة.
- **مراجعة طلبات التواصل**: المحادثات المباشرة لا تفتح إلا بموافقة الإدارة بعد حدوث إعجاب متبادل.
- **نظام الحظر والإبلاغ**: إمكانية حظر الأعضاء وتقديم بلاغات فورية للإدارة.

### 3. إدارة الملفات الشخصية والبحث
- **استكمال شامل لبيانات الزوج والزوجة**: العمر، الجنسية، التعليم، الوظيفة، الحالة الاجتماعية، وجود أبناء، الرغبة في الإنجاب، والتدخين.
- **مواصفات الشريك المطلوب**: تحديد العمر، الجنسية، المؤهل، وقبول وجود أبناء.
- **بحث وتصفية متقدمة**: فلترة بالسن، الدولة، المدينة، المؤهل، الحسابات المتصلة الآن، والترتيب بالأحدث أو الأنسب للعمر.

### 4. لوحة تحكم الإدارة (Admin Dashboard)
- **إحصائيات شاملة**: عدد الأعضاء، المتصلين الآن، الصور المعلقة، الإعجابات المتبادلة، وطلبات التواصل.
- **إدارة الأعضاء**: تفعيل أو إيقاف الحسابات المخالفة.
- **مراجعة الصور**: قبول أو رفض الصور مع توضيح سبب الرفض للعضو.
- **طلبات التواصل**: الموافقة أو الرفض على فتح المحادثات.
- **سجل المخالفات والبلاغات وتذاكر الدعم**: الرد المباشر على رسائل صفحة "تواصل معنا".

## 🚀 تشغيل وتطوير المشروع

### المتطلبات الأساسية
- **Node.js** (إصدار 18 أو أحدث)
- **npm**

### خطوات التشغيل المحلي

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# فحص الفحص البرمجي (Linter)
npm run lint

# بناء نسخة الإنتاج
npm run build
```
